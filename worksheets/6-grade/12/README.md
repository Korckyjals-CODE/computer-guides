# Workflow – Worksheets (Grade 6, Week 12)

## For the teacher

- **Use:** Use these worksheets **whenever** the topic of workflow fits your curriculum. They are self-contained learning activities, not tied to a specific computer project.
- **Format:** Students work **offline**, with **pen and paper** (and color pencils if you like). No computer or internet needed.
- **Time:** About **25 minutes** per worksheet. Each part has a suggested time (roughly 3–6 minutes) so students can pace themselves.
- **Guidance:** The text is written so that students can complete it **on their own**; no teacher guidance is required during the activity.
- **Standalone value:** Each worksheet teaches on its own. No computer project is required; optional hands-on activities may complement them if you choose.

## Learning objectives

### Technical worksheet

- Define **workflow** and list ordered steps.
- Identify **input, process, output**.
- Add **checkpoints** and versioned saves.
- Spot **bottlenecks**.
- Diagram a personal workflow.

### Social worksheet

- Practice clear **handoffs**.
- Negotiate fair deadlines.
- Improve process instead of only blaming.
- Assign visible ownership per step.
- Map a team workflow with confirmation habits.
