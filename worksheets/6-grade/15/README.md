# Conventions – Worksheets (Grade 6, Week 15)

## For the teacher

- **Use:** Use these worksheets **whenever** the topic of conventions fits your curriculum. They are self-contained learning activities, not tied to a specific computer project.
- **Format:** Students work **offline**, with **pen and paper** (and color pencils if you like). No computer or internet needed.
- **Time:** About **25 minutes** per worksheet. Each part has a suggested time (roughly 3–6 minutes) so students can pace themselves.
- **Guidance:** The text is written so that students can complete it **on their own**; no teacher guidance is required during the activity.
- **Standalone value:** Each worksheet teaches on its own. No computer project is required; optional hands-on activities may complement them if you choose.

## Learning objectives

### Technical worksheet

- A **convention** is a consistent pattern.
- Name **camel, snake and kebab** styles.
- The **order** of parts matters.
- **rewrite** a name in one style.
- Check names with a checklist.

### Social worksheet

- Conventions guide **groups**.
- Conventions differ across **cultures**.
- **adapt** my style.
- Conventions can **change**.
- Explain one convention.
