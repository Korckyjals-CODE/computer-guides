## Part 1 – What you will learn (about 3 minutes)

**What you will learn:** A **structure** is a planned way to organize data so it can be stored and found easily. Examples: a **list**, a **table**, a **tree** (folders), and a **stack**.

**Do this:**

1. **Name** one place where information is organized in a list or table.

   _________________________

2. **Circle** the structure with rows and columns: Table · Tree

## Part 2 – Common structures (about 5 minutes)

A **list** keeps items in order. A **table** uses rows and columns. A **tree** branches into parts, like folders. A **stack** adds and removes from the top.

**Real-life scenario:** A teacher keeps names in a list and grades in a table.

**Discuss with a partner or reflect in writing:** Which structure fits a class schedule?

_________________________________________

**Do this:** Match each need with the best structure. Circle one.

| Need | Structure |
|---|---|

| Names and scores | List · Table · Tree |
| Folders and subfolders | List · Table · Tree |
