Structures: Technical Worksheet

Grade 6 · Worksheet · About 25 minutes
Work with pen and paper. Use color pencils if you like. You do not need a computer or the internet.

How to use this worksheet
  • Do the parts in order from top to bottom.
  • Each part has a time so you know how long to spend.
  • Read every instruction before you write. You can do this on your own.

Part 1 – What you will learn (about 3 minutes)

What you will learn: A structure is a planned way to organize data so it can be stored and found easily. Examples: a list, a table, a tree (folders), and a stack.

Do this:

  1. Name one place where information is organized in a list or table.
  2. Circle the structure with rows and columns: Table · Tree

Part 2 – Common structures (about 5 minutes)

A list keeps items in order. A table uses rows and columns. A tree branches into parts, like folders. A stack adds and removes from the top.

Real-life scenario: A teacher keeps names in a list and grades in a table.

Discuss with a partner or reflect in writing: Which structure fits a class schedule?

Do this: Match each need with the best structure. Circle one.

NeedStructure
Shopping itemsList · Table · Tree
Names and scoresList · Table · Tree
Folders and subfoldersList · Table · Tree

Part 3 – Why structure matters (about 5 minutes)

A good structure makes data easier to search, sort, and update.

Real-life scenario: A phone book is sorted by last name. Searching is fast.

Critical thinking: What if names were in random order?

Word bank: Search · Sort · Update

Do this: Write the word that matches.

ActionWord
Find one item
Put in order
Change a value

Part 4 – Choosing (about 5 minutes)

Pick the structure that matches how you will use the data.

Real-life scenario: A school wants to store each student's name, grade, and email.

Discuss with a partner or reflect in writing: Which structure and why?

Do this:

  1. Write the columns for a small student table.
  2. Circle the better choice for names and grades: Table · Single paragraph

Part 5 – Structure sketch (about 5 minutes)

Do this: Draw a table with three columns and four rows, or a folder tree.

Write why you chose that structure.
