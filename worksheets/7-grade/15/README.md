# System Naming – Worksheets (Grade 7, Week 15)

## For the teacher

- **Use:** Use these worksheets **whenever** the topic of system naming fits your curriculum. They are self-contained learning activities, not tied to a specific computer project.
- **Format:** Students work **offline**, with **pen and paper** (and color pencils if you like). No computer or internet needed.
- **Time:** About **25 minutes** per worksheet. Each part has a suggested time (roughly 3–6 minutes) so students can pace themselves.
- **Guidance:** The text is written so that students can complete it **on their own**; no teacher guidance is required during the activity.
- **Standalone value:** Each worksheet teaches on its own. No computer project is required; optional hands-on activities may complement them if you choose.

## Learning objectives

### Technical worksheet

- Names identify **files, folders and devices**.
- Read a **path**.
- Systems have **naming limits**.
- Why **duplicates** cause trouble.
- Design a naming pattern.

### Social worksheet

- Protect **privacy** in usernames.
- Use **respectful** names.
- Understand **inclusive** naming.
- Give three **naming tips**.
- Explain a risk.
