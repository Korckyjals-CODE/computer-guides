Part 1 – What you will learn (about 3 minutes)

What you will learn: Control means a system uses a rule to move toward a goal. Feedback is a new measurement of what is happening now. In this worksheet you will compare an open loop with a closed loop, use a set point and an error, and see how bad feedback sends a sensible rule the wrong way.

Do this:

  1. Name one system that tries to hold a goal (a thermostat, a timer sprinkler, cruise control, or an automatic light).
  2. In one sentence, what goal is it trying to reach?

Part 2 – Open loop and closed loop (about 5 minutes)

An open loop follows a plan and does not check the result. A sprinkler on a timer runs for 20 minutes even if it is already raining. A closed loop measures, compares the measurement with the goal, and acts again. A thermostat turns heat on when the room is below the goal and turns it off when the room reaches it. Closed loop is not always better. It is better when the world changes and the system needs to notice.

Real-life scenario: A garden timer waters the lawn every day at 6 a.m. for 15 minutes. This week it rains every night. The lawn is soaked, and the timer still runs. A different system has a moisture sensor and skips watering when the soil is already wet.

Discuss with a partner or reflect in writing: Which system is open loop, and which is closed loop? When would the simple timer still be a reasonable choice?

Do this: Write Open loop or Closed loop.

Part 3 – Set point and error (about 5 minutes)

The set point is the goal value. The measurement is what the sensor reports now. The error is the gap between them. A controller acts to make the error smaller. If the room set point is 21°C and the sensor reads 25°C, the error is 4 degrees too warm, so cooling turns on. If you never state the set point, “make it comfortable” is not a control rule.

Real-life scenario: A classroom set point is 21°C. At noon the sensor reads 25°C. The controller starts cooling. By 12:30 the sensor reads 21°C and cooling stops.

Discuss with a partner or reflect in writing: What was the error at noon? Why did the controller stop at 12:30 instead of cooling all afternoon?

Part 4 – Bad feedback, sensible rule (about 5 minutes)

A closed loop is only as good as its feedback. If the sensor sits in the sun, the controller may cool a room that people find cold. The rule is fine. The measurement is not. Moving the sensor, or adding a second check, is often a better fix than replacing the whole controller.

Critical thinking: A thermostat sensor is on a sunny windowsill. People in the room feel cold, but the controller keeps cooling. Explain the mistake in one or two sentences. Then say where you would put the sensor.
