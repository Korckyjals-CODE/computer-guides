Work with pen and paper. Use color pencils if you like. You do not need a computer or the internet.

How to use this worksheet
  • Do the parts in order from top to bottom.
  • Each part has a time so you know how long to spend.
  • Read every instruction before you write. You can do this on your own.

Part 1 – What you will learn (about 3 minutes)

What you will learn: A control system pushes toward a goal that some people did not choose. In this worksheet you will ask who sets the set point, when people need an override, and how a strict rule can be unfair when the situation changes.

Do this:

  1. Name one automatic rule at school or at home (lights, heat, a quiz timer, a door lock, or another).
  2. Circle who you think set that rule: Students · A teacher or family · A company or the building · I do not know

Part 2 – Who sets the goal (about 5 minutes)

The set point looks technical. It is also a decision about whose comfort counts. If one office sets the only thermostat, every other room lives with that choice. People in a hotter room are not “using the system wrong.” They never received the control.

Real-life scenario: The school thermostat is locked. The main office is comfortable at the chosen set point. A classroom on the sunny side is much warmer. Students ask to change it. The panel says only a building account can adjust the goal.

Discuss with a partner or reflect in writing: Whose comfort became the set point? What would a fairer way to share that control look like?

Do this: Decide who should be able to do each action. You may name more than one group.

Action Who should be able to do it? Why
Choose the normal daytime set point
Ask for a one-hour change in one hot room
See which rooms are far from the set point
Lock the panel so no class can change anything

Part 3 – A way to pause the rule (about 5 minutes)

An override is a deliberate pause or change by a person when the automatic rule no longer fits. A system with no override treats every exception as a mistake. Safety rules can stay firm. Comfort and timing rules usually need a human pause.

Real-life scenario: Hallway lights use a motion sensor and turn off quickly. A class sits on the floor for a reading circle. The lights go out because no one is walking. There is no switch the teacher can hold on for the next 20 minutes.

Critical thinking: Should this light system have an override? Write yes or no, and say who should be allowed to use it. Then name one control you would not let students override, and why.

Do this: Write Needs an override or Can stay automatic.

Situation Needs an override or can stay automatic? Who may use the override, if anyone
Lights go out while a class sits still
A freezer alarm when the temperature rises
A quiz timer that cannot pause for a fire drill
A door that stays locked during a fire alarm

Part 4 – Strict control, changed situation (about 5 minutes)

Automatic rules are often sold as fair because they treat everyone the same. Sameness is not fairness when people did not have the same conditions. A timer that ignores a disrupted class punishes students for a building event.

Real-life scenario: A quiz locks when the timer hits zero. A fire drill uses 15 of the 30 minutes. The system still locks. Students who were outside cannot finish. The dashboard shows a high number of “incomplete” scores.

Discuss with a partner or reflect in writing: What goal was the timer controlling? What did that goal fail to measure?

Do this: Compare two rules for the quiz.

Rule A: timer always locks Rule B: teacher can add back the drill time
What stays the same for every class
What happens after a fire drill
Who can correct an unfair result
Which rule would you choose, and why?

Part 6 – Check what you learned (about 2 minutes)

Checklist. Put a ✓ in the box when it is true for you.

  • □ I can explain that a set point is someone’s choice about whose comfort or time counts.
  • □ I can say who should be able to see or change a locked control.
  • □ I can decide when a system needs an override.
  • □ I can tell a safety lock from a timer that should pause when conditions change.
