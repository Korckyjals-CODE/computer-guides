# Control – Worksheets (Grade 7, Week 9)

## For the teacher

- **Use:** Use these worksheets **whenever** the topic of control fits your curriculum. They are self-contained learning activities, not tied to a specific computer project.
- **Format:** Students work **offline**, with **pen and paper** (and color pencils if you like). No computer or internet needed.
- **Time:** About **25 minutes** per worksheet. Each part has a suggested time (roughly 3–6 minutes) so students can pace themselves.
- **Guidance:** The text is written so that students can complete it **on their own**; no teacher guidance is required during the activity.
- **Standalone value:** Each worksheet teaches on its own. No computer project is required; optional hands-on activities may complement them if you choose.

## Learning objectives

### Technical worksheet

- Explain **control** as a rule that moves a system toward a goal.
- Distinguish an **open loop** from a **closed loop** that uses feedback.
- Compute a plain-language **error** from a set point and a measurement, and choose an action.
- Show how a bad sensor makes a reasonable controller do the wrong thing.
- Draw a closed loop and state what a person should still be able to change.

### Social worksheet

- Treat a set point as a decision about whose comfort or schedule counts.
- Assign who should see or change a locked building control.
- Decide which situations need a human **override**.
- Compare a rigid timer with a rule that can restore time lost to a building emergency.
- Write a three-part policy: goal, who sets it, and when a person can pause it.
