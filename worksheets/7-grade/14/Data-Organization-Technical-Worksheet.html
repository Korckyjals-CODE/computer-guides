Data Organization: Technical Worksheet

Grade 7 · Worksheet · About 25 minutes
Work with pen and paper. Use color pencils if you like. You do not need a computer or the internet.

Name: Grade/Section: Date:
How to use this worksheet
  • Do the parts in order from top to bottom.
  • Each part has a time so you know how long to spend.
  • Read every instruction before you write. You can do this on your own.

Part 1 – What you will learn (about 3 minutes)

What you will learn: Data organization is arranging data so it is accurate, easy to find, and ready to use. Key ideas: categories, consistent formats, naming rules, and metadata (data about data).

Do this:

  1. Name one set of data you would like to organize, such as music or contacts.
  2. Circle data about data: Metadata · Backup

Part 2 – Categories and formats (about 5 minutes)

Group related data into categories. Use the same format each time, for example dates as 2026-11-20.

Real-life scenario: A list has dates written as 11/20, 20 Nov, and Nov 20th.

Discuss with a partner or reflect in writing: What problem could that cause?

Do this: Decide which format is consistent. Circle the best.

EntriesConsistent?
2026-11-20, 2026-11-21Yes · No
20 Nov, 11/21Yes · No
Nov 20th, 21/11/2026Yes · No

Part 3 – Metadata (about 5 minutes)

Metadata describes a file: author, date, size, and type. It helps you search and sort.

Real-life scenario: A photo's metadata shows the date and place it was taken.

Critical thinking: How can metadata help find a file?

Word bank: Author · Date · Size · Type

Do this: Write the metadata that matches.

QuestionMetadata
Who made it?
When was it made?
How big is it?

Part 4 – Cleaning data (about 5 minutes)

Remove duplicates, fix errors, and fill missing values before using data.

Real-life scenario: A contact list has two entries for the same person and one with no number.

Discuss with a partner or reflect in writing: What would you do first?

Do this:

  1. Write two steps to clean a list.
  2. Circle the cleaner list: No duplicates · Many duplicates

Part 5 – Data plan (about 5 minutes)

Do this: Draw a table that organizes ten contacts with four columns.

Write one naming rule you would use.

Part 6 – Check what you learned (about 2 minutes)

Checklist. Put a ✓ in the box when it is true for you.

  • □ I can group data into categories.
  • □ I use consistent formats.
  • □ I know what metadata is.
  • □ I can clean data.
  • □ I plan how to organize data.

When all boxes are checked, you have reviewed the main ideas from this worksheet.
