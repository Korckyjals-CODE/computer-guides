# Análisis de fallos – Hojas de trabajo (DC3B, Semana 11)

## Para el docente / Teacher notes

- **Uso / Use:** Cuando el tema de análisis de fallos encaje en el currículo. Son actividades autónomas; no dependen de un proyecto en computadora. / Use whenever failure analysis fits your plan. Standalone; no computer project required.
- **Formato / Format:** Offline, bolígrafo y papel. Unos **25 minutos** por hoja. / Offline, pen and paper. About **25 minutes** each.
- **Autonomía / Guidance:** El alumnado puede completarlas por su cuenta. / Self-guided; no teacher help needed during the activity.
- **Valor independiente / Standalone value:** Cada hoja enseña por sí misma. / Each worksheet teaches on its own.

## Objetivos de aprendizaje / Learning objectives

### Técnica / Technical
- Separar **síntoma** de **causa** y reunir evidencia.
- Identificar una **causa raíz** con datos (no con culpas).
- Aplicar métodos básicos: **5 porqués** y línea de tiempo.
- Esbozar un flujo de análisis y registrar hallazgos.

### Social
- Analizar el **impacto** de un fallo en usuarios y equipos.
- Practicar **responsabilidad** y reporte ético (hechos, sin ocultar).
- Redactar un aviso o reporte claro durante la falla.
- Definir roles de reporte para reducir daño y rumores.
