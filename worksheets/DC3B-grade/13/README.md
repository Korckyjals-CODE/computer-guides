# Optimización de interfaces – Hojas de trabajo (DC3B, Semana 13)

## Para el docente

- **Uso:** Usa estas hojas **cuando** el tema de optimización de interfaces encaje en tu currículo. Son actividades autónomas, no ligadas a un proyecto de computadora.
- **Formato:** Los estudiantes trabajan **sin computadora**, con **bolígrafo y papel** (y colores si quieren).
- **Tiempo:** Unos **25 minutos** por hoja. Cada parte indica un tiempo sugerido.
- **Guía:** El texto permite completar la actividad **de forma autónoma**.
- **Valor autónomo:** Cada hoja enseña por sí misma. No se requiere un proyecto en computadora.

## Objetivos de aprendizaje

### Hoja técnica

- Definir la **optimización de interfaces**.
- Aplicar **jerarquía visual** para priorizar acciones.
- Usar **affordances** y **retroalimentación** claras.
- Distinguir fricción útil de fricción inútil.
- Proponer un rediseño concreto tras una auditoría rápida.

### Hoja social

- Ver la optimización como decisión **social**.
- Identificar quién puede quedar **fuera** de una interfaz.
- Reconocer **patrones oscuros** y su costo ético.
- Cuidar el **consentimiento** en valores por defecto.
- Proponer una mejora más justa e inclusiva.
