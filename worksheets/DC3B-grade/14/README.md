# Ciclo de Vida de los Datos – Hojas de trabajo (DC3B, Semana 14)

## Para el docente

- **Uso:** Usa estas hojas **cuando** el tema de ciclo de vida de los datos encaje en tu currículo. Son actividades autónomas, no ligadas a un proyecto de computadora.
- **Formato:** Los estudiantes trabajan **sin computadora**, con **bolígrafo y papel** (y colores si quieren).
- **Tiempo:** Unos **25 minutos** por hoja. Cada parte indica un tiempo sugerido.
- **Guía:** El texto permite completar la actividad **de forma autónoma**.
- **Valor autónomo:** Cada hoja enseña por sí misma. No se requiere un proyecto en computadora.

## Objetivos de aprendizaje

### Hoja técnica

- Nombrar las **seis etapas**.
- La **retención**.
- La **eliminación segura**.
- Unir acciones con etapas.
- Planifico los datos de principio a fin.

### Hoja social

- El **consentimiento**.
- El derecho a **eliminar**.
- Valoro la **transparencia**.
- Protejo la **privacidad**.
- Respeto los datos de las personas.
