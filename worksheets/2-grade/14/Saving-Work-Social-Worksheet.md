## Part 1 – What you will learn (about 3 minutes)

**What you will learn:** Saving work also means respecting others' work. We keep our files in our own folders, ask before using a classmate's file, and never delete work that is not ours.

**Do this:**

1. **Name** one rule for using shared computers.

   _________________________

2. **Circle** the respectful choice: Save in my own folder · Save over a friend's file

---

## Part 2 – My own folder (about 5 minutes)

On shared computers, each student needs a folder. This keeps work from getting mixed up.

**Real-life scenario:** Two students save a file with the same name in the same folder. One file is lost.

**Discuss with a partner or reflect in writing:** How can students avoid this?

_________________________________________

**Do this:** Circle **Respectful** or **Not respectful**.

| Action | Respectful? |
|---|---|
| Use my own folder | Respectful · Not respectful |
| Delete someone's file | Respectful · Not respectful |
| Add my name to the file | Respectful · Not respectful |
| Save over a classmate's work | Respectful · Not respectful |

## Part 3 – Honest work (about 5 minutes)

Saved work shows what you did. We never put our name on another person's work.

**Real-life scenario:** Mia copies a friend's saved story and writes her own name.

**Critical thinking:** Why is that unfair?

## Part 4 – Backups and care (about 5 minutes)

We keep extra copies of important work. We ask a teacher before deleting anything.

**Real-life scenario:** Ben's file is deleted by mistake. Luckily a copy was saved.

**Discuss with a partner or reflect in writing:** Why is a copy useful?

_________________________________________

**Do this:**

1. **Write** one thing you would ask a teacher before deleting.

   _________________________

2. **Circle** the best choice: Ask before deleting · Delete without asking
