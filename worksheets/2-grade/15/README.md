# Naming Files – Worksheets (Grade 2, Week 15)

## For the teacher

- **Use:** Use these worksheets **whenever** the topic of naming files fits your curriculum. They are self-contained learning activities, not tied to a specific computer project.
- **Format:** Students work **offline**, with **pen and paper** (and color pencils if you like). No computer or internet needed.
- **Time:** About **25 minutes** per worksheet. Each part has a suggested time (roughly 3–6 minutes) so students can pace themselves.
- **Guidance:** The text is written so that students can complete it **on their own**; no teacher guidance is required during the activity.
- **Standalone value:** Each worksheet teaches on its own. No computer project is required; optional hands-on activities may complement them if you choose.

## Learning objectives

### Technical worksheet

- A file needs a **name**.
- Names can use **letters** and **numbers**.
- Some **symbols** are not allowed.
- Tell two files apart with **numbers**.
- Write a good file name.

### Social worksheet

- A clear name helps **others**.
- Teams can have a **naming rule**.
- **ask first** before changing names.
- **respect** other people's files.
- Say one class rule.
