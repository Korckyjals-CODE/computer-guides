Naming Files: Technical Worksheet

Grade 2 · Worksheet · About 25 minutes
Work with pen and paper. Use color pencils if you like. You do not need a computer or the internet.

Name: Grade/Section: Date:
How to use this worksheet
  • Do the parts in order from top to bottom.
  • Each part has a time so you know how long to spend.
  • Read every instruction before you write. You can do this on your own.

Part 1 – What you will learn (about 3 minutes)

What you will learn: When you save your work, the computer asks for a file name. A good name helps you find your work again later.

Do this:

  1. Write a name you could give to a story about a frog.
  2. Circle the name that tells what the file is: Frog story · File1

Part 2 – Saving with a name (about 5 minutes)

To save, you type a name and press Save. The name goes at the top of the box that opens.

Real-life scenario: Eli saves a drawing but skips the name. The computer calls it “Untitled”.

Discuss with a partner or reflect in writing: What problem could this cause later?

Part 3 – What goes in a name (about 5 minutes)

A name can use letters, numbers, and a dash. Some symbols are not allowed, like / or ?.

Real-life scenario: Mina types “Who?” as a name. The computer says the name is not allowed.

Critical thinking: What can she type instead?

Part 4 – Same name, new name (about 5 minutes)

Two files in one folder cannot have the same name. We add a number to tell them apart, like Cat-1 and Cat-2.

Real-life scenario: Noah makes two drawings of the sun and wants both called Sun.

Discuss with a partner or reflect in writing: What can he do?

Do this:

  1. Write two names for two sun drawings.
  2. Circle the better pair: Sun-1 and Sun-2 · Sun and Sun

Part 5 – My file names (about 5 minutes)

Do this: Draw two files. Write a good name inside each file.

Write why the names are good.

Part 6 – Check what you learned (about 2 minutes)

Checklist. Put a ✓ in the box when it is true for you.

  • □ I know a file needs a name.
  • □ I know names can use letters and numbers.
  • □ I know some symbols are not allowed.
  • □ I can tell two files apart with numbers.
  • □ I can write a good file name.

When all boxes are checked, you have reviewed the main ideas from this worksheet.
