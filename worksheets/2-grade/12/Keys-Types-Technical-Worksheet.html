Keys Types: Technical Worksheet

Grade 2 · Worksheet · About 25 minutes
Work with pen and paper. Use color pencils if you like. You do not need a computer or the internet.

  • Do the parts in order from top to bottom.

Part 1 – What you will learn (about 3 minutes)

What you will learn: A keyboard has many keys. Keys are not all the same. Some keys type letters. Some type numbers. Some are special keys that do jobs like making a space or starting a new line. In this worksheet you will name and sort key types.

Do this:

  1. Name one key you have pressed on a keyboard or tablet keyboard.
  2. Circle one key type you already know: Letter keys · Number keys · Special keys

Part 2 – Letter keys (about 5 minutes)

Letter keys are the keys that type the alphabet (A, B, C … Z). Most of the middle of a keyboard is letter keys. You use them to write words and names.

Real-life scenario: Mia wants to type her name. She finds the M key, then the I key, then the A key. Those are letter keys.

Discuss with a partner or reflect in writing: Why do we need many letter keys on a keyboard?

Do this: Write L if it is a letter key. Write No if it is not.

Part 3 – Number keys (about 5 minutes)

Number keys type the digits 0–9. Many keyboards have a row of number keys above the letter keys. You use them for ages, dates, scores, and phone numbers.

Real-life scenario: Sam writes the date for today's worksheet. He presses 1, then 2. Those are number keys.

Critical thinking: Can you write the number twelve with letter keys only? Why or why not?

Do this: Circle the number keys in this list.

3 · B · 0 · Enter · 9 · Space · 5

Then write one thing you might type with number keys (e.g. your age or today's date).

Part 4 – Special keys (about 5 minutes)

Special keys do jobs that are not typing a letter or a number. Common ones:

  • Space bar — makes a blank space between words
  • Enter (or Return) — starts a new line
  • Backspace — erases the last thing you typed
  • Shift — helps make a capital letter when you hold it and press a letter key
Real-life scenario: Leo typed “ilike cats” with no spaces. He puts the cursor between “i” and “like”, then taps the space bar. Now it reads “i like cats”.

Discuss with a partner or reflect in writing: Which special key would you use if you typed the wrong letter by mistake?

Part 5 – Draw and sort keys (about 5 minutes)

Do this:

  1. Draw a simple keyboard (a few rows of keys is enough). Label at least one letter key, one number key, and one special key.
  1. Write one sentence naming the three key types you labeled.

Part 6 – Check what you learned (about 2 minutes)

Checklist. Put a ✓ in the box when it is true for you.

  • □ I know a keyboard has different types of keys.
  • □ I can name a letter key (like A or M).
  • □ I can name a number key (like 3 or 0).
  • □ I know at least one special key (space bar, Enter, Backspace, or Shift).
  • □ I can sort keys into letter, number, and special types.

When all boxes are checked, you have reviewed the main ideas from this worksheet.
