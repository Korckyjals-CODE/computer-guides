# Keys Types – Worksheets (Grade 2, Week 12)

## For the teacher

- **Use:** Use these worksheets **whenever** the topic of keys types fits your curriculum. They are self-contained learning activities, not tied to a specific computer project.
- **Format:** Students work **offline**, with **pen and paper** (and color pencils if you like). No computer or internet needed.
- **Time:** About **25 minutes** per worksheet. Each part has a suggested time (roughly 3–6 minutes) so students can pace themselves.
- **Guidance:** The text is written so that students can complete it **on their own**; no teacher guidance is required during the activity.
- **Standalone value:** Each worksheet teaches on its own. No computer project is required; optional hands-on activities may complement them if you choose.

## Learning objectives

### Technical worksheet

- Know that a **keyboard** has different **types of keys**.
- Name and identify **letter keys**.
- Name and identify **number keys**.
- Name common **special keys** (space bar, Enter, Backspace, Shift) and match them to jobs.
- Sort keys into letter, number, and special types in a drawing or table.

### Social worksheet

- Help classmates find keys **without taking over**.
- Use special keys **fairly** with a partner.
- Show **patience** while others hunt for keys.
- Ask before changing someone else's text.
- Draw or state one helper tip.
