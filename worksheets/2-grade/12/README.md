# Keys Types – Worksheet (Grade 2, Week 12)

## For the teacher

- **Use:** Use this worksheet **whenever** the topic of keys types fits your curriculum. It is a self-contained learning activity, not tied to a specific computer project.
- **Format:** Students work **offline**, with **pen and paper** (and color pencils if you like). No computer or internet needed.
- **Time:** About **25 minutes**. Each part has a suggested time (roughly 3–6 minutes) so students can pace themselves.
- **Guidance:** The text is written so that students can complete it **on their own**; no teacher guidance is required during the activity.
- **Standalone value:** The worksheet teaches on its own. No computer project is required.

## Learning objectives

### Technical worksheet

- Know that a **keyboard** has different **types of keys**.
- Name and identify **letter keys**.
- Name and identify **number keys**.
- Name common **special keys** (space bar, Enter, Backspace, Shift) and match them to jobs.
- Sort keys into letter, number, and special types in a drawing or table.
