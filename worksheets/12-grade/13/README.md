# Design Systems – Worksheets (Grade 12, Week 13)

## For the teacher

- **Use:** Use these worksheets **whenever** the topic of design systems fits your curriculum. They are self-contained learning activities, not tied to a specific computer project.
- **Format:** Students work **offline**, with **pen and paper** (and color pencils if you like). No computer or internet needed.
- **Time:** About **25 minutes** per worksheet. Each part has a suggested time (roughly 3–6 minutes) so students can pace themselves.
- **Guidance:** The text is written so that students can complete it **on their own**; no teacher guidance is required during the activity.
- **Standalone value:** Each worksheet teaches on its own. No computer project is required; optional hands-on activities may complement them if you choose.

## Learning objectives

### Technical worksheet

- Define **design tokens**.
- Explain **components** and **patterns**.
- Why **governance** matters.
- Weigh **consistency vs. flexibility**.
- Plan how to propose a component.

### Social worksheet

- A system carries **values**.
- Describe **accessibility by default**.
- Ownership and **collaboration** matter.
- Think about **inclusive language**.
- Propose a value for a system.
