# Human Factors – Worksheets (Grade 12, Week 12)

## For the teacher

- **Use:** Use these worksheets **whenever** the topic of human factors fits your curriculum. They are self-contained learning activities, not tied to a specific computer project.
- **Format:** Students work **offline**, with **pen and paper** (and color pencils if you like). No computer or internet needed.
- **Time:** About **25 minutes** per worksheet. Each part has a suggested time (roughly 3–6 minutes) so students can pace themselves.
- **Guidance:** The text is written so that students can complete it **on their own**; no teacher guidance is required during the activity.
- **Standalone value:** Each worksheet teaches on its own. No computer project is required; optional hands-on activities may complement them if you choose.

## Learning objectives

### Technical worksheet

- Define **human factors** for systems design.
- Map basic error types to defenses.
- Improve feedback for mental models.
- Simplify choices under stress.
- Produce a case card with a design defense.

### Social worksheet

- Prefer system fixes over scapegoating.
- Enable safe near-miss reporting.
- Practice blameless learning habits.
- Require oversight of automation.
- Propose a digital safety culture plan.
