Folders: Technical Worksheet

Grade 5 · Worksheet · About 25 minutes
Work with pen and paper. Use color pencils if you like. You do not need a computer or the internet.

Name: Grade/Section: Date:
How to use this worksheet
  • Do the parts in order from top to bottom.
  • Each part has a time so you know how long to spend.
  • Read every instruction before you write. You can do this on your own.

Part 1 – What you will learn (about 3 minutes)

What you will learn: A folder (or directory) is a container that groups files and other folders. Folders form a hierarchy, like a tree, with a root at the top and paths that show where a file lives.

Do this:

  1. Write the path of a file you know, such as School > Math > Test.
  2. Circle the top of a folder tree: Root · Leaf

Part 2 – Hierarchy (about 5 minutes)

A parent folder contains child folders. The path Documents/School/Math goes from the parent to the child.

Real-life scenario: Ines stores Quiz.docx in Documents/School/Math.

Discuss with a partner or reflect in writing: Which folder is the parent of Math?

Do this: Decide if each statement is true. Circle the best answer.

StatementTrue or false
School is the parent of MathTrue · False
Math is the rootTrue · False
A path shows where a file isTrue · False

Part 3 – Paths (about 5 minutes)

A path lists folders in order, separated by a slash. It tells the computer exactly where to find a file.

Real-life scenario: Hugo wants to find Photo.png in Pictures/Trips/2026.

Critical thinking: Why must a path be exact?

Word bank: Path · Parent · Child · Root

Do this: Write the term that matches.

DescriptionTerm
Folder inside another
Folder that contains others
Location of a file

Part 4 – Making a plan (about 5 minutes)

Plan folders before saving. Group by subject or by project, and avoid too many levels.

Real-life scenario: A student has 15 folders on the desktop and one folder five levels deep.

Discuss with a partner or reflect in writing: How would you reorganize them?

Do this:

  1. Write a folder path for a science report.
  2. Circle the clearer path: Science/Reports/Plants · Stuff/New/Misc

Part 5 – Folder tree (about 5 minutes)

Do this: Draw a folder tree with one root and at least five folders and files.

Write the path to one file in your tree.

Part 6 – Check what you learned (about 2 minutes)

Checklist. Put a ✓ in the box when it is true for you.

  • □ I know what a folder is.
  • □ I can explain parent and child.
  • □ I can write a path.
  • □ I plan folders clearly.
  • □ I avoid too many levels.

When all boxes are checked, you have reviewed the main ideas from this worksheet.
