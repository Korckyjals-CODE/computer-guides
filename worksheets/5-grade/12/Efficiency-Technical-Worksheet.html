Efficiency: Technical Worksheet

Grade 5 · Worksheet · About 25 minutes
Work with pen and paper. Use color pencils if you like. You do not need a computer or the internet.

Name: Grade/Section: Date:
How to use this worksheet
  • Do the parts in order from top to bottom.
  • Each part has a time so you know how long to spend.
  • Read every instruction before you write. You can do this on your own.

Part 1 – What you will learn (about 3 minutes)

What you will learn: Efficiency means getting good results with less wasted time and effort—using the right tools, shortcuts, folders, and steps—without rushing so much that you create errors.

Do this:

  1. Name a school computer task that sometimes feels slow.
  2. Circle true efficiency: Smart steps + accuracy · Only speed with many mistakes

Part 2 – Speed vs accuracy (about 5 minutes)

Going faster is not efficient if you must redo the work. True efficiency balances speed and accuracy.

Real-life scenario: Two students write the same paragraph. One finishes first with five typos and spends ten minutes fixing. The other types a bit slower and is done once.

Discuss with a partner or reflect in writing: Who used time more efficiently? Why?

Do this: Circle Often or Rarely.

ApproachMore efficient?
Plan headings, then typeOften · Rarely
Type anything, fix chaos later alwaysOften · Rarely
Save early so you do not lose workOften · Rarely

Part 3 – Tools that save steps (about 5 minutes)

Efficiency tools include shortcuts, clear file names, folders, templates, and Find (Ctrl+F). Each removes repeated hunting.

Real-life scenario: Aya renames “asdf.docx” to “Science-Lab-Nov6.docx” and saves it in Science/. Next week she finds it in seconds.

Critical thinking: How does a clear file name save future time?

Word bank: Shortcut · Clear file name · Folder · Find/search

Part 4 – Reduce context switching (about 5 minutes)

Jumping between many tabs and chats wastes focus. Efficiency improves when you finish one small goal before switching.

Real-life scenario: Noah writes one sentence, checks messages, opens five tabs, forgets his sentence, and restarts.

Discuss with a partner or reflect in writing: What is one way to protect focus for ten minutes?

Do this:

  1. Write a 10-minute plan for one homework task (3 steps).
  2. Circle an efficiency habit: Close extra tabs first · Open every site “just in case”

Part 5 – Efficiency sketch (about 5 minutes)

Do this: Draw a before/after: messy desktop vs organized folders + one shortcut you will use.

Write one efficiency goal for this week.

Part 6 – Check what you learned (about 2 minutes)

Checklist. Put a ✓ in the box when it is true for you.

  • □ I know efficiency balances speed and accuracy.
  • □ I can name tools that save steps (shortcuts, names, folders, Find).
  • □ I know messy switching wastes time.
  • □ I can plan a short focused work block.
  • □ I set one efficiency goal.

When all boxes are checked, you have reviewed the main ideas from this worksheet.
