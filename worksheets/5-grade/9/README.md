# Systems – Worksheets (Grade 5, Week 9)

## For the teacher

- **Use:** Use these worksheets **whenever** the topic of systems fits your curriculum. They are self-contained learning activities, not tied to a specific computer project.
- **Format:** Students work **offline**, with **pen and paper** (and color pencils if you like). No computer or internet needed.
- **Time:** About **25 minutes** per worksheet. Each part has a suggested time (roughly 3–6 minutes) so students can pace themselves.
- **Guidance:** The text is written so that students can complete it **on their own**; no teacher guidance is required during the activity.
- **Standalone value:** Each worksheet teaches on its own. No computer project is required; optional hands-on activities may complement them if you choose.

## Learning objectives

### Technical worksheet

- Explain a **system** as parts that work together for a purpose.
- Identify **input**, **process**, and **output** in everyday examples.
- Locate the one part whose failure stops an otherwise working system.
- Classify parts as a **person**, a **tool**, or **information**.
- Draw a small system with arrows, an input, and an output.

### Social worksheet

- Describe who a system was planned for and who it treats as an exception.
- Propose a change so a different arrival time or walking speed is still a normal path.
- Decide when a failure should be fixed in the system rather than blamed on a person.
- Write a fair order for a shared printer.
- Sketch two changes and name who each one helps.
