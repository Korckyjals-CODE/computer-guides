File Systems: Social Worksheet

Grade 8 · Worksheet · About 25 minutes
Work with pen and paper. Use color pencils if you like. You do not need a computer or the internet.

Name: Grade/Section: Date:
How to use this worksheet
  • Do the parts in order from top to bottom.
  • Each part has a time so you know how long to spend.
  • Read every instruction before you write. You can do this on your own.

Part 1 – What you will learn (about 3 minutes)

What you will learn: File systems affect people through access, privacy, and ownership. Permissions decide who can read or change data, and shared drives need clear etiquette.

Do this:

  1. Name one rule for a shared drive.
  2. Circle the respectful rule: Use permissions properly · Open every folder

Part 2 – Permissions and privacy (about 5 minutes)

The file system stores permissions so only the right users can read or edit files.

Real-life scenario: A student can open a folder meant for teachers.

Discuss with a partner or reflect in writing: What should the student do?

Do this: Circle Right or Wrong.

ActionRight or wrong?
Close it and reportRight · Wrong
Read the answer keyRight · Wrong
Tell a teacher the permissions are wrongRight · Wrong
Copy the filesRight · Wrong

Part 3 – Ownership (about 5 minutes)

The owner of a file decides who can use it. Respecting ownership builds trust.

Real-life scenario: A student renames a team file without telling the team.

Critical thinking: Why can this cause trouble?

Word bank: Owner · Permission · Trust

Do this: Write the best word.

Part 4 – Shared drive etiquette (about 5 minutes)

Name files clearly, keep folders tidy, and do not leave junk files on shared drives.

Real-life scenario: A shared drive is full of files named “test1”, “test2”.

Discuss with a partner or reflect in writing: How can the group clean it up?

Do this:

  1. Write one etiquette rule for shared drives.
  2. Circle the better habit: Delete your own old files · Delete others' files

Part 5 – Drive etiquette poster (about 5 minutes)

Do this: Draw a poster with three rules for a shared drive.

Write which rule matters most.

Part 6 – Check what you learned (about 2 minutes)

Checklist. Put a ✓ in the box when it is true for you.

  • □ I respect permissions.
  • □ I respect ownership.
  • □ I follow drive etiquette.
  • □ I keep shared spaces tidy.
  • □ I report access mistakes.

When all boxes are checked, you have reviewed the main ideas from this worksheet.
