Part 1 – What you will learn (about 3 minutes)

What you will learn: A file system is how an operating system names, stores, and finds files on a drive. Examples: NTFS, FAT32, exFAT, ext4, and APFS. It tracks names, locations, sizes, and permissions.

Do this:

  1. Name one operating system you have used and where it saves files.
  2. Circle the part that stores file locations: File system · Monitor

Part 2 – What a file system does (about 5 minutes)

It splits a drive into small blocks, keeps a table of where each file's blocks are, and records details like size and date.

Real-life scenario: When you open Report.docx, the file system finds its blocks and delivers them.

Discuss with a partner or reflect in writing: Why is a table of locations important?

Part 3 – Common file systems (about 5 minutes)

Different file systems fit different needs. FAT32 works widely but has a 4 GB file limit. NTFS adds permissions. exFAT is good for large files on USB drives.

Real-life scenario: A 6 GB video will not copy to a FAT32 USB.

Critical thinking: Which file system could fix this?

Word bank: FAT32 · NTFS · exFAT

Part 4 – Formatting and fragmentation (about 5 minutes)

Formatting prepares a drive with a file system and erases data. Fragmentation means a file's pieces are scattered, which can slow old hard drives.

Real-life scenario: A student formats a USB without copying the files first.

Discuss with a partner or reflect in writing: What was lost and why?

Do this:

  1. Write one step to do before formatting.
  2. Circle the safer habit: Back up first · Format right away
