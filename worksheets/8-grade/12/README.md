# Human Input Limits – Worksheets (Grade 8, Week 12)

## For the teacher

- **Use:** Use these worksheets **whenever** the topic of human input limits fits your curriculum. They are self-contained learning activities, not tied to a specific computer project.
- **Format:** Students work **offline**, with **pen and paper** (and color pencils if you like). No computer or internet needed.
- **Time:** About **25 minutes** per worksheet. Each part has a suggested time (roughly 3–6 minutes) so students can pace themselves.
- **Guidance:** The text is written so that students can complete it **on their own**; no teacher guidance is required during the activity.
- **Standalone value:** Each worksheet teaches on its own. No computer project is required; optional hands-on activities may complement them if you choose.

## Learning objectives

### Technical worksheet

- Identify major **human input limits**.
- Link working memory to interface design.
- Apply motor/target placement ideas.
- Relate fatigue to error rates.
- Sketch a limit-aware redesign.

### Social worksheet

- Practice **empathy** around input mistakes.
- Argue for equitable assessment beyond speed.
- Propose break/undo-friendly culture.
- Avoid public shaming of errors.
- Write an advocacy memo for a fix.
