# Usabilidad – Hojas de trabajo (DC3A, Semana 13)

## Para el docente

- **Uso:** Usa estas hojas **cuando** el tema de usabilidad encaje en tu currículo. Son actividades autónomas, no ligadas a un proyecto de computadora.
- **Formato:** Los estudiantes trabajan **sin computadora**, con **bolígrafo y papel** (y colores si quieren).
- **Tiempo:** Unos **25 minutos** por hoja. Cada parte indica un tiempo sugerido.
- **Guía:** El texto permite completar la actividad **de forma autónoma**.
- **Valor autónomo:** Cada hoja enseña por sí misma. No se requiere un proyecto en computadora.

## Objetivos de aprendizaje

### Hoja técnica

- Las cinco **metas de usabilidad**.
- Explicar una **prueba de usabilidad**.
- Medir **tiempo** y **éxito**.
- Proponer una mejora.
- Comparar dos diseños.

### Hoja social

- La usabilidad afecta a **todas las personas**.
- Nombrar grupos que suelen quedar fuera.
- Explicar la prueba con **usuarios variados**.
- Dar **opiniones amables**.
- Sugerir un cambio inclusivo.
