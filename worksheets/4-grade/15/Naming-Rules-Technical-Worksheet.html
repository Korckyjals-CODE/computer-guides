Naming Rules: Technical Worksheet

Grade 4 · Worksheet · About 25 minutes
Work with pen and paper. Use color pencils if you like. You do not need a computer or the internet.

How to use this worksheet
  • Do the parts in order from top to bottom.
  • Each part has a time so you know how long to spend.
  • Read every instruction before you write. You can do this on your own.

Part 1 – What you will learn (about 3 minutes)

What you will learn: Naming rules are agreements about how to name files. Rules like using clear words, avoiding special symbols, and adding numbers make files easy to sort and find.

Do this:

  1. Name one rule you follow in class and explain why it exists.
  2. Circle the idea behind a naming rule: Be consistent · Be random

Part 2 – Common naming rules (about 5 minutes)

Typical rules: use clear words, avoid spaces and symbols like / ? * : and use dashes or underscores. Keep names short.

Real-life scenario: A student saves “Project: Final?.docx”. The computer refuses the name.

Discuss with a partner or reflect in writing: Which symbols caused the problem?

Part 3 – Order with numbers (about 5 minutes)

Numbers at the start sort files in order. Use 01, 02, 03 so 10 does not come before 2.

Real-life scenario: Files named 1, 2, 10 appear in the order 1, 10, 2.

Critical thinking: How would 01, 02, 10 fix it?

Word bank: 01 · 02 · 10

Part 4 – Dates and versions (about 5 minutes)

Many rules add a date like 2026-11-30 and a version like v2. The most recent file is then easy to spot.

Real-life scenario: Ana has Essay-final, Essay-final2 and Essay-really-final.

Discuss with a partner or reflect in writing: Which naming rule could help?

Do this:

  1. Write a name for the second version of an essay.
  2. Circle the clearer name: Essay-v2 · Essay-really-final

Part 5 – Rule poster (about 5 minutes)

Do this: Draw a poster with three naming rules.

Write which rule helps you most.

Checklist. Put a ✓ in the box when it is true for you.
