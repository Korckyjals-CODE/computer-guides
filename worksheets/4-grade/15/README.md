# Naming Rules – Worksheets (Grade 4, Week 15)

## For the teacher

- **Use:** Use these worksheets **whenever** the topic of naming rules fits your curriculum. They are self-contained learning activities, not tied to a specific computer project.
- **Format:** Students work **offline**, with **pen and paper** (and color pencils if you like). No computer or internet needed.
- **Time:** About **25 minutes** per worksheet. Each part has a suggested time (roughly 3–6 minutes) so students can pace themselves.
- **Guidance:** The text is written so that students can complete it **on their own**; no teacher guidance is required during the activity.
- **Standalone value:** Each worksheet teaches on its own. No computer project is required; optional hands-on activities may complement them if you choose.

## Learning objectives

### Technical worksheet

- Why **naming rules** exist.
- Avoid **special symbols**.
- Use **numbers** to sort files.
- Add **versions** and dates when needed.
- Explain a rule.

### Social worksheet

- Rules work when people **agree**.
- Think about **fairness**.
- Remind others **kindly**.
- **change** a rule that does not work.
- Write a team promise.
