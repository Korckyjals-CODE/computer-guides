# Shortcuts – Worksheets (Grade 4, Week 12)

## For the teacher

- **Use:** Use these worksheets **whenever** the topic of shortcuts fits your curriculum. They are self-contained learning activities, not tied to a specific computer project.
- **Format:** Students work **offline**, with **pen and paper** (and color pencils if you like). No computer or internet needed.
- **Time:** About **25 minutes** per worksheet. Each part has a suggested time (roughly 3–6 minutes) so students can pace themselves.
- **Guidance:** The text is written so that students can complete it **on their own**; no teacher guidance is required during the activity.
- **Standalone value:** Each worksheet teaches on its own. No computer project is required; optional hands-on activities may complement them if you choose.

## Learning objectives

### Technical worksheet

- Define a **keyboard shortcut** and **modifier** keys.
- Match common shortcuts (copy, paste, undo, save).
- **Select** text before edit shortcuts.
- Explain when Undo helps.
- Create a personal cheat card.

### Social worksheet

- Ask before changing **shared** text with shortcuts.
- Teach shortcuts without shaming others.
- Report shortcut accidents honestly.
- Suggest fair team rules.
- Design a shortcut agreement poster.
