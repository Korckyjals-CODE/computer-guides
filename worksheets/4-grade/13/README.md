# Navigation – Worksheets (Grade 4, Week 13)

## For the teacher

- **Use:** Use these worksheets **whenever** the topic of navigation fits your curriculum. They are self-contained learning activities, not tied to a specific computer project.
- **Format:** Students work **offline**, with **pen and paper** (and color pencils if you like). No computer or internet needed.
- **Time:** About **25 minutes** per worksheet. Each part has a suggested time (roughly 3–6 minutes) so students can pace themselves.
- **Guidance:** The text is written so that students can complete it **on their own**; no teacher guidance is required during the activity.
- **Standalone value:** Each worksheet teaches on its own. No computer project is required; optional hands-on activities may complement them if you choose.

## Learning objectives

### Technical worksheet

- Tell **menus**, **links**, and **buttons** apart.
- What a **path** is.
- Use **Back**, **Home**, and search.
- Too many tabs can confuse me.
- Read a folder path.

### Social worksheet

- To **ask** before opening unknown links.
- Explain steps **patiently**.
- Why schools have **online rules**.
- Name two safe browsing habits.
- Help a classmate.
