File Organization: Technical Worksheet

Grade 4 · Worksheet · About 25 minutes
Work with pen and paper. Use color pencils if you like. You do not need a computer or the internet.

Name: Grade/Section: Date:
How to use this worksheet
  • Do the parts in order from top to bottom.
  • Each part has a time so you know how long to spend.
  • Read every instruction before you write. You can do this on your own.

Part 1 – What you will learn (about 3 minutes)

What you will learn: File organization means placing files in clear folders with clear names so you can find them fast. A folder inside another folder is a subfolder.

Do this:

  1. Write how you organize your school notebooks.
  2. Circle the folder inside another folder: Subfolder · Desktop

Part 2 – Folders and subfolders (about 5 minutes)

Folders can hold folders. For example, a folder School can have subfolders Math and Science.

Real-life scenario: Rita keeps School > Math > Homework.

Discuss with a partner or reflect in writing: Why use subfolders?

Do this: Match each file to its folder. Circle the best folder.

Part 3 – Good names (about 5 minutes)

A good name is short and clear. It can include the topic and the date, like Plants_2026-11.

Real-life scenario: Files named “doc1”, “new”, and “final” are hard to tell apart.

Critical thinking: How would you rename them?

Word bank: Clear · Short · Date

Part 4 – Find fast (about 5 minutes)

Keep a simple system: few main folders, clear names, and regular cleaning of old files.

Real-life scenario: Sam has 200 files on the desktop and cannot find his project.

Discuss with a partner or reflect in writing: What three steps would you take?

Do this:

  1. Write one rule for keeping files tidy.
  2. Circle the better way: Folders by subject · Everything on the desktop

Part 5 – My folder tree (about 5 minutes)

Do this: Draw a folder tree with one main folder and three subfolders.

Write names for each folder.

Part 6 – Check what you learned (about 2 minutes)

Checklist. Put a ✓ in the box when it is true for you.

  • □ I know what file organization is.
  • □ I can make subfolders.
  • □ I write clear names.
  • □ I can find files fast.
  • □ I clean up old files.

When all boxes are checked, you have reviewed the main ideas from this worksheet.
