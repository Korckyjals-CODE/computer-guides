File Organization: Social Worksheet

Grade 4 · Worksheet · About 25 minutes
Work with pen and paper. Use color pencils if you like. You do not need a computer or the internet.

Name: Grade/Section: Date:
How to use this worksheet
  • Do the parts in order from top to bottom.
  • Each part has a time so you know how long to spend.
  • Read every instruction before you write. You can do this on your own.

Part 1 – What you will learn (about 3 minutes)

What you will learn: Organized files make teamwork easier. When a group follows the same folder rules, everyone can find and use the work.

Do this:

  1. Name one time organization helped a team.
  2. Circle the helpful rule: Everyone uses the same folders · Everyone uses a different plan

Part 2 – Shared folders (about 5 minutes)

In a group project, a shared folder holds everyone's work. Clear names show who did what.

Real-life scenario: Four students save in different places. The teacher cannot find the project.

Discuss with a partner or reflect in writing: How can the group fix this?

Do this: Circle Helpful or Not helpful.

ActionHelpful?
Agree on folder namesHelpful · Not helpful
Save work anywhereHelpful · Not helpful
Put your name in the file nameHelpful · Not helpful
Rename others' files without askingHelpful · Not helpful

Part 3 – Respecting others' files (about 5 minutes)

Do not move, rename, or delete files that belong to others without asking.

Real-life scenario: Leo renames Ana's file. Ana cannot find it.

Critical thinking: How should Leo have acted?

Word bank: Ask · Permission · Respect

Do this: Write the best word.

SituationWord
I ... before changing a file
I need ... for a friend's file
I show ... for their work

Part 4 – Teaching a friend (about 5 minutes)

We can help classmates learn to organize. Kind words and examples work best.

Real-life scenario: Zoe shows a friend how to make a Math folder.

Discuss with a partner or reflect in writing: How can you teach kindly?

Do this:

  1. Write one kind sentence to a friend learning folders.
  2. Circle the kind helper: Show with patience · Laugh at the mess

Part 5 – Team folders (about 5 minutes)

Do this: Draw a shared folder for a team of three with each person's file.

Write one rule your team would follow.

Part 6 – Check what you learned (about 2 minutes)

Checklist. Put a ✓ in the box when it is true for you.

  • □ I follow team folder rules.
  • □ I ask before moving others' files.
  • □ I show respect.
  • □ I can teach kindly.
  • □ I help my team find things.

When all boxes are checked, you have reviewed the main ideas from this worksheet.
