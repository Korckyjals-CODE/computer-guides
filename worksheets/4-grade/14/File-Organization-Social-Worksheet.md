## How to use this worksheet

- Do the parts **in order** from top to bottom.
- Each part has a **time** so you know how long to spend.
- Read every instruction before you write. You can do this on your own.

---

## Part 1 – What you will learn (about 3 minutes)

**What you will learn:** Organized files make teamwork easier. When a group follows the same folder rules, everyone can find and use the work.

**Do this:**

1. **Name** one time organization helped a team.

   _________________________

2. **Circle** the helpful rule: Everyone uses the same folders · Everyone uses a different plan

---

## Part 2 – Shared folders (about 5 minutes)

In a group project, a shared folder holds everyone's work. Clear names show who did what.

**Real-life scenario:** Four students save in different places. The teacher cannot find the project.

**Discuss with a partner or reflect in writing:** How can the group fix this?

_________________________________________

**Do this:** Circle **Helpful** or **Not helpful**.

| Action | Helpful? |
|---|---|
| Agree on folder names | Helpful · Not helpful |
| Save work anywhere | Helpful · Not helpful |
| Put your name in the file name | Helpful · Not helpful |
| Rename others' files without asking | Helpful · Not helpful |

---

## Part 3 – Respecting others' files (about 5 minutes)

Do not move, rename, or delete files that belong to others without asking.

**Real-life scenario:** Leo renames Ana's file. Ana cannot find it.

**Critical thinking:** How should Leo have acted?

_________________________________________

**Word bank:** *Ask* · *Permission* · *Respect*

**Do this:** Write the best word.

| Situation | Word |
|---|---|
| I ... before changing a file | _____ |
| I need ... for a friend's file | _____ |
| I show ... for their work | _____ |
