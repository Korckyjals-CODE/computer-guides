# UX Input Design – Worksheets (Grade 9, Week 12)

## For the teacher

- **Use:** Use these worksheets **whenever** the topic of ux input design fits your curriculum. They are self-contained learning activities, not tied to a specific computer project.
- **Format:** Students work **offline**, with **pen and paper** (and color pencils if you like). No computer or internet needed.
- **Time:** About **25 minutes** per worksheet. Each part has a suggested time (roughly 3–6 minutes) so students can pace themselves.
- **Guidance:** The text is written so that students can complete it **on their own**; no teacher guidance is required during the activity.
- **Standalone value:** Each worksheet teaches on its own. No computer project is required; optional hands-on activities may complement them if you choose.

## Learning objectives

### Technical worksheet

- Apply labels, affordances, and feedback.
- Judge defaults and constraints.
- Use progressive disclosure.
- Critique silent system states.
- Wireframe a short input flow.

### Social worksheet

- Identify **dark patterns**.
- Advocate for accessible input.
- Practice informed consent habits.
- Resist unsafe “Allow all” pressure.
- Pitch an ethical redesign.
