Good Names: Technical Worksheet

Grade 3 · Worksheet · About 25 minutes
Work with pen and paper. Use color pencils if you like. You do not need a computer or the internet.

Name: Grade/Section: Date:
How to use this worksheet
  • Do the parts in order from top to bottom.
  • Each part has a time so you know how long to spend.
  • Read every instruction before you write. You can do this on your own.

Part 1 – What you will learn (about 3 minutes)

What you will learn: A good name is clear, short, and tells what is in the file. It helps you find the file quickly.

Do this:

  1. Write a good name for a file with your math homework.
  2. Circle the best file name: Math homework · Stuff

Part 2 – Clear and short (about 5 minutes)

A good name has two or three words. It should say the topic. Very long names are hard to read.

Real-life scenario: Lena names her file “my very very long homework about plants that I did on Monday afternoon”.

Discuss with a partner or reflect in writing: How could she shorten it?

Part 3 – Say what it is (about 5 minutes)

The best names tell the topic and sometimes the date or number. Example: Volcano-Report-1.

Real-life scenario: Two files are called Report and Report-final. Which one is the volcano report?

Critical thinking: How could the names say more?

Part 4 – Fix the name (about 5 minutes)

A name can be improved. Take away extra words, add the topic, and avoid spaces if you can. Use a dash.

Real-life scenario: A file named “new new new” holds a picture of a bridge.

Discuss with a partner or reflect in writing: What is a better name?

Do this:

  1. Write a better name for a picture of a bridge.
  2. Circle the improved name: Bridge-Picture · new new new

Part 5 – Name the pictures (about 5 minutes)

Do this: Draw three small pictures. Give each a good name.

Write which name is your best.

Part 6 – Check what you learned (about 2 minutes)

Checklist. Put a ✓ in the box when it is true for you.

  • □ I know a good name is clear.
  • □ I know a good name is short.
  • □ I can include the topic.
  • □ I can add a number if needed.
  • □ I can fix a poor name.

When all boxes are checked, you have reviewed the main ideas from this worksheet.
