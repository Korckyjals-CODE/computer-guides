Good Names: Social Worksheet

Grade 3 · Worksheet · About 25 minutes
Work with pen and paper. Use color pencils if you like. You do not need a computer or the internet.

Name: Grade/Section: Date:
How to use this worksheet
  • Do the parts in order from top to bottom.
  • Each part has a time so you know how long to spend.
  • Read every instruction before you write. You can do this on your own.

Part 1 – What you will learn (about 3 minutes)

What you will learn: Good names help the whole class. When everyone writes clear names, we find files faster and feel less stress.

Do this:

  1. Write one way a good name helps a friend.
  2. Circle the helpful choice: Clear names · Silly names

Part 2 – Names that help everyone (about 5 minutes)

If a class folder has clear names, a substitute teacher can find anything. This saves time.

Real-life scenario: The teacher is away. The substitute cannot find the homework files.

Discuss with a partner or reflect in writing: What could the class do to help?

Do this: Circle Helps or Does not help.

ChoiceResult
Clear namesHelps · Does not help
Secret codesHelps · Does not help
Topic in the nameHelps · Does not help
Names like “thing”Helps · Does not help

Part 3 – Being kind in names (about 5 minutes)

Names on shared files should be respectful. No jokes about others or mean words.

Real-life scenario: A file called “Sam is silly” is in the class folder.

Critical thinking: How might Sam feel?

Word bank: kind · respect · joke

Do this: Fill in the best word.

SentenceWord
Names should be ...
We show ... to everyone
A ... can hurt

Part 4 – Teaching a friend (about 5 minutes)

You can teach a friend how to write good names. Be patient and give an example.

Real-life scenario: Your friend names every file “file”.

Discuss with a partner or reflect in writing: How can you help kindly?

Do this:

  1. Write one helpful sentence.
  2. Circle the kind help: Show an example · Laugh

Part 5 – Class naming tips (about 5 minutes)

Do this: Draw a small poster with two tips for good names.

Write your favorite tip.

Part 6 – Check what you learned (about 2 minutes)

Checklist. Put a ✓ in the box when it is true for you.

  • □ I know good names help others.
  • □ I use respectful words.
  • □ I can teach a friend patiently.
  • □ I give examples.
  • □ I can write a naming tip.

When all boxes are checked, you have reviewed the main ideas from this worksheet.
