## Part 1 – What you will learn (about 3 minutes)

**What you will learn:** Every file has a **type**. The type tells the computer what is inside: a picture, a document, a song, or a video. The type is shown at the end of the name, after a dot, called the **extension**.

**Do this:**

1. **Name** one kind of file you have used, like a picture.

   _________________________

2. **Circle** the extension for a picture: .jpg · .mp3

## Part 3 – The extension (about 5 minutes)

The **extension** is the short ending of a file name, such as **.txt**. It helps the computer choose the right program to open it.

**Real-life scenario:** Tom renames Homework.docx to Homework.mp3. It no longer opens in a word program.

**Critical thinking:** Why is it risky to change the extension?

_________________________________________

**Word bank:** *Extension* · *Name* · *Program*

**Do this:** Write the word that matches.

Pick the type that fits the job. Photos use .jpg. Written work uses .docx or .txt.
