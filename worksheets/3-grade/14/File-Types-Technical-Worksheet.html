File Types: Technical Worksheet

Grade 3 · Worksheet · About 25 minutes
Work with pen and paper. Use color pencils if you like. You do not need a computer or the internet.

Name: Grade/Section: Date:
How to use this worksheet
  • Do the parts in order from top to bottom.
  • Each part has a time so you know how long to spend.
  • Read every instruction before you write. You can do this on your own.

Part 1 – What you will learn (about 3 minutes)

What you will learn: Every file has a type. The type tells the computer what is inside: a picture, a document, a song, or a video. The type is shown at the end of the name, after a dot, called the extension.

Do this:

  1. Name one kind of file you have used, like a picture.
  2. Circle the extension for a picture: .jpg · .mp3

Part 2 – Kinds of files (about 5 minutes)

Common types: documents (.docx, .txt), images (.jpg, .png), audio (.mp3), and video (.mp4).

Real-life scenario: Lia has a file called Holiday.jpg. It is a photo.

Discuss with a partner or reflect in writing: What kind of file is Song.mp3?

Do this: Match each file with its kind. Circle the best kind.

Part 3 – The extension (about 5 minutes)

The extension is the short ending of a file name, such as .txt. It helps the computer choose the right program to open it.

Real-life scenario: Tom renames Homework.docx to Homework.mp3. It no longer opens in a word program.

Critical thinking: Why is it risky to change the extension?

Word bank: Extension · Name · Program

Do this: Write the word that matches.

Part 4 – Choose the right type (about 5 minutes)

Pick the type that fits the job. Photos use .jpg. Written work uses .docx or .txt.

Real-life scenario: Mia wants to send a small drawing to a friend.

Discuss with a partner or reflect in writing: Which type would you choose and why?

Do this:

  1. Write the file type you would use for a text note.
  2. Circle the best match: Photo → .jpg · Photo → .mp3

Part 5 – My file types (about 5 minutes)

Do this: Draw four icons for four file types. Label each with its extension.

Write one file you have on a computer and its type.

Part 6 – Check what you learned (about 2 minutes)

Checklist. Put a ✓ in the box when it is true for you.

  • □ I know file types.
  • □ I know what an extension is.
  • □ I can name .jpg, .mp3, .docx.
  • □ I can choose a type for a job.
  • □ I do not change extensions by accident.

When all boxes are checked, you have reviewed the main ideas from this worksheet.
