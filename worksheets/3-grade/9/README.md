# Everyday Automation – Worksheets (Grade 3, Week 9)

## For the teacher

- **Use:** Use these worksheets **whenever** the topic of everyday automation fits your curriculum. They are self-contained learning activities, not tied to a specific computer project.
- **Format:** Students work **offline**, with **pen and paper** (and color pencils if you like). No computer or internet needed.
- **Time:** About **25 minutes** per worksheet. Each part has a suggested time (roughly 3–6 minutes) so students can pace themselves.
- **Guidance:** The text is written so that students can complete it **on their own**; no teacher guidance is required during the activity.
- **Standalone value:** Each worksheet teaches on its own. No computer project is required; optional hands-on activities may complement them if you choose.

## Learning objectives

### Technical worksheet

- Explain **automation** as a machine that follows steps after a **trigger**, without a person doing every step.
- Identify a trigger and one repeated step for everyday machines such as a dishwasher, microwave, or automatic door.
- Describe **repeat**: the machine can run the same steps again.
- Label **trigger**, **job**, and **stop**, and say why a machine needs a way to finish.
- Plan a simple classroom helper by drawing those three parts.

### Social worksheet

- Notice that a machine can save time for some people and still leave work for others.
- Choose safer behavior around machines that move, close, or get hot.
- Write a **fair rule** for a shared classroom machine.
- Put sharing actions in an order that does not let one person hold the machine.
- Make a short sign that states a kind, clear rule for using a machine.
