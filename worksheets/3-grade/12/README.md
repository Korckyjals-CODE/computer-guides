# Typing Logic – Worksheets (Grade 3, Week 12)

## For the teacher

- **Use:** Use these worksheets **whenever** the topic of typing logic fits your curriculum. They are self-contained learning activities, not tied to a specific computer project.
- **Format:** Students work **offline**, with **pen and paper** (and color pencils if you like). No computer or internet needed.
- **Time:** About **25 minutes** per worksheet. Each part has a suggested time (roughly 3–6 minutes) so students can pace themselves.
- **Guidance:** The text is written so that students can complete it **on their own**; no teacher guidance is required during the activity.
- **Standalone value:** Each worksheet teaches on its own. No computer project is required; optional hands-on activities may complement them if you choose.

## Learning objectives

### Technical worksheet

- Explain **typing logic** as a plan for clear text.
- Use **spaces** between words correctly.
- Use **Shift** for capitals.
- Fix typos carefully, one at a time.
- Plan a short sentence before typing.

### Social worksheet

- Support a typing partner with **patience**.
- Give **kind** feedback on typos.
- Check shared text for readability.
- Take responsibility for group writing quality.
- Create a class tip card.
