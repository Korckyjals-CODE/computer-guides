# Precision – Worksheets (Grade 3, Week 13)

## For the teacher

- **Use:** Use these worksheets **whenever** the topic of precision fits your curriculum. They are self-contained learning activities, not tied to a specific computer project.
- **Format:** Students work **offline**, with **pen and paper** (and color pencils if you like). No computer or internet needed.
- **Time:** About **25 minutes** per worksheet. Each part has a suggested time (roughly 3–6 minutes) so students can pace themselves.
- **Guidance:** The text is written so that students can complete it **on their own**; no teacher guidance is required during the activity.
- **Standalone value:** Each worksheet teaches on its own. No computer project is required; optional hands-on activities may complement them if you choose.

## Learning objectives

### Technical worksheet

- **precision** means exact.
- Use **zoom** or slower movements.
- Name a tool that helps (arrow keys, mouse speed).
- To **check** my work.
- **undo** fixes mistakes.

### Social worksheet

- **accessibility** means technology for everyone.
- Name two helpful tools.
- People need different settings.
- Respect people's **pace**.
- Suggest a kind action.
