# Productivity Systems – Worksheets (Grade 10, Week 12)

## For the teacher

- **Use:** Use these worksheets **whenever** the topic of productivity systems fits your curriculum. They are self-contained learning activities, not tied to a specific computer project.
- **Format:** Students work **offline**, with **pen and paper** (and color pencils if you like). No computer or internet needed.
- **Time:** About **25 minutes** per worksheet. Each part has a suggested time (roughly 3–6 minutes) so students can pace themselves.
- **Guidance:** The text is written so that students can complete it **on their own**; no teacher guidance is required during the activity.
- **Standalone value:** Each worksheet teaches on its own. No computer project is required; optional hands-on activities may complement them if you choose.

## Learning objectives

### Technical worksheet

- Define a **productivity system**.
- Capture and clarify into next actions.
- Apply a prioritization framework.
- Run review loops.
- Map personal tools into a system.

### Social worksheet

- Align on shared sources of truth.
- Set humane notification norms.
- Recognize equity in capacity.
- Mirror personal tools into shared trackers.
- Draft a team operating agreement.
