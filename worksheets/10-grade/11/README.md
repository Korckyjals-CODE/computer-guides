# Failure Analysis – Worksheets (Grade 10, Week 11)

## For the teacher

- **Use:** Whenever failure analysis fits your curriculum. Self-contained; not tied to a computer project.
- **Format:** Offline, pen and paper. About **25 minutes** each.
- **Guidance:** Students can work independently.
- **Standalone value:** Each worksheet teaches on its own.

## Files

### Technical
- **Failure-Analysis-Technical-Worksheet.html** / **.md**

### Social
- **Failure-Analysis-Social-Worksheet.html** / **.md**

## Learning objectives

### Technical
- Separate symptoms from causes; isolate with evidence.
- Classify hardware / software / process failures.
- Document incidents with prevention steps.
- Sketch an analysis flow.

### Social
- Prefer learning culture over blame culture.
- Communicate clearly during downtime.
- Consider unequal impact and ethical reporting.
- Structure a people-aware after-action review.
