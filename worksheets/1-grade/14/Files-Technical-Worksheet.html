Files: Technical Worksheet

Grade 1 · Worksheet · About 25 minutes
Work with pen and paper. Use color pencils if you like. You do not need a computer or the internet.

Name: Grade/Section: Date:
How to use this worksheet
  • Do the parts in order from top to bottom.
  • Each part has a time so you know how long to spend.
  • Read every instruction before you write. You can do this on your own.

Part 1 – What you will learn (about 3 minutes)

What you will learn: A file is one piece of work saved on a computer. A picture, a story, or a song can each be a file. A folder is like a box that holds many files.

Do this:

  1. Name one thing you could save as a file, like a picture.
  2. Circle the box that holds files: Folder · Spoon

Part 2 – What is a file (about 5 minutes)

A file keeps your work safe. Every file has a name so we can find it again.

Real-life scenario: Ana draws a cat on the computer. She saves it as a file named Cat.

Discuss with a partner or reflect in writing: Why does a file need a name?

Do this: Circle Yes or No.

ThingCan it be a file?
A pictureYes · No
A storyYes · No
A songYes · No
A real appleYes · No

Part 3 – Files and folders (about 5 minutes)

A folder holds files together, like a school bag holds notebooks. Files go inside folders.

Real-life scenario: Leo puts all his animal pictures in a folder named Animals.

Critical thinking: Why is a folder helpful?

Word bank: File · Folder · Name

Do this: Fill in the word that matches.

ClueWord

One saved piece of work
Helps us find a file

Part 4 – Open and save (about 5 minutes)

To save means to keep your work. To open means to look at it again.

Real-life scenario: Mia finishes a drawing. She clicks Save before she turns off the computer.

Discuss with a partner or reflect in writing: What can happen if you forget to save?

Do this:

  1. Write the word for keeping your work.
  2. Circle the best choice: Save your work · Turn off without saving

Part 5 – My file drawing (about 5 minutes)

Do this: Draw a folder with two files inside. Write a name on each file.

Write one name you could give to a drawing file.

Part 6 – Check what you learned (about 2 minutes)

Checklist. Put a ✓ in the box when it is true for you.

  • □ I know a file is saved work.
  • □ I know a folder holds files.
  • □ I know a file has a name.
  • □ I know save keeps my work.
  • □ I can open a file to see it again.

When all boxes are checked, you have reviewed the main ideas from this worksheet.
