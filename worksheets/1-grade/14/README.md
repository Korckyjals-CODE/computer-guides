# Files – Worksheets (Grade 1, Week 14)

## For the teacher

- **Use:** Use these worksheets **whenever** the topic of files fits your curriculum. They are self-contained learning activities, not tied to a specific computer project.
- **Format:** Students work **offline**, with **pen and paper** (and color pencils if you like). No computer or internet needed.
- **Time:** About **25 minutes** per worksheet. Each part has a suggested time (roughly 3–6 minutes) so students can pace themselves.
- **Guidance:** The text is written so that students can complete it **on their own**; no teacher guidance is required during the activity.
- **Standalone value:** Each worksheet teaches on its own. No computer project is required; optional hands-on activities may complement them if you choose.

## Files

### Worksheet 1 – Technical

## Learning objectives

### Technical worksheet

- A **file** is saved work.
- A **folder** holds files.
- A file has a **name**.
- **save** keeps my work.
- Open a file to see it again.

### Social worksheet

- To **ask first** before opening a friend's file.
- To keep folders **tidy**.
- **share** work with kind people.
- Say something **kind** about work.
- Say one rule for sharing files.
