# Keyboard Basics – Worksheets (Grade 1, Week 12)

## For the teacher

- **Use:** Use these worksheets **whenever** the topic of keyboard basics fits your curriculum. They are self-contained learning activities, not tied to a specific computer project.
- **Format:** Students work **offline**, with **pen and paper** (and color pencils if you like). No computer or internet needed.
- **Time:** About **25 minutes** per worksheet. Each part has a suggested time (roughly 3–6 minutes) so students can pace themselves.
- **Guidance:** The text is written so that students can complete it **on their own**; no teacher guidance is required during the activity.
- **Standalone value:** Each worksheet teaches on its own. No computer project is required; optional hands-on activities may complement them if you choose.

## Learning objectives

### Technical worksheet

- Explain what a **keyboard** and **keys** are.
- Find **letter keys** and the **space bar**.
- Know that **Enter** can start a new line.
- Press keys **softly**.
- Draw or state one keyboard tip.

### Social worksheet

- Recognize school keyboards are for the **whole class**.
- **Take turns** without grabbing.
- Leave a keyboard **ready** for the next student.
- **Tell a grown-up** when something looks wrong.
- Make a short sharing poster.
